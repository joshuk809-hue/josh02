# Emil Kowalski skills

Source: https://github.com/emilkowalski/skills (MIT, see `../LICENSE-emilkowalski`).

Pick the skill that fits the request and follow its `SKILL.md` (in the sibling folder of the same name). If the user typed `/emilskill` with no task, list these and ask what they want to do. With no clear match, default to `emil-design-eng`.

| Skill | Use it for |
|---|---|
| `emil-design-eng` | General UI polish, component design and animation decisions (the main skill) |
| `animate` | Building a new web animation or transition |
| `animate-expo` | Animations, gestures and haptics in React Native / Expo |
| `review-animations` | Strict critique of existing animation code |
| `improve-animations` | Codebase-wide motion audit with prioritized plans |
| `find-animation-opportunities` | Finding places that should (and shouldn't) animate |
| `animation-vocabulary` | Naming a motion effect from a vague description |
| `apple-design` | Apple-style fluid motion, springs, gestures, materials, typography |
| `mobile-native` | Making a web app feel native on phones (100vh, tap highlights, safe areas…) |
| `break-ui` | Stress-testing UI with worst-case data |
| `pick-ui-library` | Choosing a trusted library instead of hand-rolling one |
| `prototype` | Building several UI variants with a switcher |
| `ask-sonner` | Setting up or debugging Sonner toasts |
| `write-swift` | Writing or reviewing modern Swift |

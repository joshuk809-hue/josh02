Hamburgheria del Contadino · Carta Fedeltà

Three cards, from the first sprout to the reserve.

Every customer carries their fidelity card in Apple Wallet or Google Wallet. The card grows with them: it starts as a sprout, becomes the harvest, and the best guests are set aside in the Riserva. The QR code on each card opens the restaurant's fidelity page with that customer's card number.

Going live on Apple Wallet

  1. In an Apple Developer account, create a Pass Type ID (for example pass.it.hamburgheriadelcontadino.fidelity) and download its certificate.
  2. Export the certificate and key as PEM files, and download Apple's WWDR G4 certificate.
  3. Run node tools/build-wallet-passes.js --card LHC-10458 --name "Marco Bianchi" --spend 1290 --points 312 with the APPLE_* variables set.
  4. Send the resulting .pkpass by email or link: one tap adds it to Wallet.

The repo includes the pass bundles for all three tiers. They install once signed with your certificate.

Going live on Google Wallet

  1. In the Google Pay & Wallet Console, request Google Wallet API access. You get an Issuer ID.
  2. Create a service account with Wallet access, then download its JSON key.
  3. Upload wallet/art/ to any public HTTPS address (Google fetches the images from there).
  4. Run the same build command with GOOGLE_* set: each customer gets an "Add to Google Wallet" link.

The classes for all three tiers and the customer objects are ready in wallet/build/google/.
